# راهنمای ارسال گزارش روزانه (فرمت MD)

در حال حاضر گزارش روزانه در قالب فایل اکسل ارسال می‌شود. اما تصمیم داریم با همکاری تعدادی از اینترن‌ها، ارسال گزارش در قالب فایل md را بررسی کنیم. فایل md در واقع متن ساده است با کمی فرمت مشخص؛ در همه سیستم‌عامل‌ها و پلتفرم‌ها باز می‌شود، در نوشتن داکیومنت‌ها و در گیت‌هاب خیلی استفاده می‌شود و در هوش مصنوعی هم کاربرد زیادی دارد.

با تغییر از اکسل به md، می‌توان از گیت‌هاب به‌عنوان بستر ارسال گزارش استفاده کرد. این کار مزایای زیادی دارد که مهم‌تر از همه آشنایی اینترن‌ها با گیت و گیت‌هاب است.

## پیش‌نیازها

- حساب کاربری گیت‌هاب (GitHub)
- نصب گیت (Git) روی سیستم‌عامل خود: [https://git-scm.com/downloads](https://git-scm.com/downloads)

## گام به گام مراحل ارسال گزارش

### گام ۱ — Fork کردن ریپو (فقط برای اولین بار)

**ریپو** یعنی مخزن (Repository): همان جایی در گیت‌هاب که فایل‌های این پروژه (از جمله قالب گزارش) در آن نگهداری می‌شود. **Fork کردن** یعنی یک کپی از ریپوی اصلی در حساب کاربری خودتان بسازید.

1. وارد ریپوی اصلی شوید: [https://github.com/serajoddin-aliabadi/cs-daily-report](https://github.com/serajoddin-aliabadi/cs-daily-report)
2. روی دکمه **Fork** (بالا سمت راست) کلیک کنید. این کار یک کپی از ریپو را در **حساب کاربری خودتان** می‌سازد و روی ریپوی اصلی تأثیری ندارد.

### گام ۲ — Clone کردن ریپو (برای اولین بار)

عملیات **Clone کردن** یعنی دانلود یک کپی از ریپوی خودتان روی سیستم. اگر تا به حال کلون نکرده‌اید، ریپوی فورک‌شده را کلون کنید:

```bash
git clone https://github.com/<username>/cs-daily-report.git
cd cs-daily-report
```

توجه: به‌جای `<username>` نام کاربری خود را در گیت‌هاب بگذارید.

### گام ۳ — ساخت فایل گزارش استپ

از روی فایل `TEMPLATE.md` یک کپی بسازید و نام آن را طبق الگوی زیر بگذارید:

```
CSI - Report - [Intern's Name] - [Course Name] - [Step No]
```

مثال: `CSI - Report - Ali Alavi - Web - Step1.md`

```bash
# Windows (PowerShell)
Copy-Item TEMPLATE.md "CSI - Report - Ali Alavi - Web - Step1.md"

# Mac / Linux
cp TEMPLATE.md "CSI - Report - Ali Alavi - Web - Step1.md"
```

فقط فایل گزارش استپ خود را ویرایش کنید و فایل `TEMPLATE.md` را دست نزنید. با شروع هر استپ جدید، یک کپی جدید با شماره استپ جدید بسازید.

### گام ۴ — پر کردن گزارش روزانه

قالب گزارش به هفته‌ها (Week) و روزها (Monday تا Sunday) تقسیم شده است:

- بالای هر روز تاریخ آن را به‌صورت شمسی بنویسید (مثلاً `1405-05-14`).
- در هر روزی که فعالیت داشتید، بلوک نمونه‌ی Task را از کادر کدِ بالای همان هفته کپی کنید و زیر روز بچسبانید (بالای خط جداکننده‌ی `---`). اگر فعالیتی نداشتید، در قالب متن این مورد را ذکر کنید.
- برای هر تسک: عنوان تسک و لینک‌های شبکه‌های اجتماعی (تلگرام، لینکدین، توییتر) را پر کنید. اگر تسک‌های بیشتری هم داشتید، بلوک را تکرار کنید.
- در پایان هر هفته: ساعت کاری و رضایت هفتگی (Satisfaction) را کامل کنید.
- زیر هر روز، ساعت کاری همان روز را هم بنویسید (ردیف `Hours Today`).
- در پایان هفته، جمع ساعات هفته را در جدول `Overall Weekly Assessment` (ردیف `Total Hours This Week`) وارد کنید.
- فراموش نکنید جدول بالای فایل (Intern Information) را هم ویرایش کنید: نام، شماره استپ، لینک سند استپ، ساعت توافقی هفتگی و ددلاین.

### گام ۵ — کامیت و پوش روزانه

بعد از کامل کردن گزارش هر روز، یک کامیت بزنید و روی گیت‌هاب پوش کنید:

```bash
git add "CSI - Report - Ali Alavi - Web - Step1.md"
git commit -m "Step 1 - Day 1405-xx-xx report"
git push origin main
```

هر روز که گزارش می‌دهید باید حداقل یک کامیت و پوش داشته باشید.

> اگر برای اولین بار است که روی این سیستم از گیت استفاده می‌کنید، ابتدا هویت گیت را تنظیم کنید (یک بار کافی است):
>
> ```bash
> git config --global user.name "Your Name"
> git config --global user.email "your-email@example.com"
> ```

### گام ۶ — گرفتن لینک کامیت

1. ریپوی خود را در گیت‌هاب باز کنید (آدرس ریپوی فورک‌شده).
2. روی تب **Commits** کلیک کنید.
3. روی عنوان کامیت مورد نظر کلیک کنید.
4. آدرس (URL) صفحه را کپی کنید. این همان لینک کامیت است.

لینک کامیت به این شکل است:
`https://github.com/<username>/cs-daily-report/commit/<sha>`

### گام ۷ — ارسال لینک در تلگرام

لینک کامیت را در گروه **CS Internship - Coordination**، تاپیک **Reports** ارسال کنید و کوردینیتور خود را منشن کنید (مثلاً `@[نام کوردیناتور]`).

مثال پیام گزارش روزانه:

```
گزارش روز ۱۴۰۵-05-14 — استپ ۱

https://github.com/<username>/cs-daily-report/commit/<sha>

@[coordinator]
[hashtags...]
```

## نکات مهم

- هر روز حداقل یک کامیت و پوش لازم است؛ گزارش هر روز باید جداگانه ارسال شود.
- فقط فایل گزارش استپ خود را تغییر دهید؛ `TEMPLATE.md` و بقیه فایل‌ها را دست نزنید.
- با شروع استپ جدید، یک کپی جدید از تمپلیت با شماره استپ جدید بسازید.
- اگر دستور push با خطا مواجه شد (مثلاً به‌خاطر تغییرات روی گیت‌هاب)، ابتدا `git pull origin main` را اجرا کنید و دوباره push کنید.
- برای همگام‌سازی فورک خود با ریپوی اصلی در صورت تغییر آن، از خود گیت‌هاب (بدون نیاز به دستور) استفاده کنید:
  1. ریپوی فورک‌شده خود را در گیت‌هاب باز کنید.
  2. اگر ریپوی اصلی به‌روز شده باشد، بالای لیست فایل‌ها دکمه‌ی **Sync fork** را می‌بینید؛ روی آن کلیک کنید.
  3. در پنجره‌ی باز شده روی **Update branch** کلیک کنید تا فورک شما با ریپوی اصلی همگام شود.
  4. سپس روی سیستم خود `git pull origin main` را اجرا کنید تا تغییرات روی سیستم شما هم اعمال شود.

## ابزار پیشنهادی: Obsidian + پلاگین Git

برای ویرایش گزارش می‌توانید از هر ویرایشگر Markdown (مثل VS Code) استفاده کنید، اما ابزار پیشنهادی ما **Obsidian** است:

- رایگان است و فایل‌ها را به‌صورت فایل‌های متنی ساده Markdown روی دستگاه شما ذخیره می‌کند — دقیقاً همان فرمتی که گیت و گیت‌هاب استفاده می‌کنند؛ هیچ فرمت اختصاصی‌ای تحمیل نمی‌کند.
- بدون اینترنت و آفلاین هم کار می‌کند. (هرچند برای کامیت و پوش، اینترنت لازم است)
- روی ویندوز، مک، لینوکس و همچنین **اندروید و iOS** در دسترس است ([https://obsidian.md/mobile](https://obsidian.md/mobile)).
- با پلاگین (Community Plugin) به‌نام **Git** ساخته‌ی Vinzent03 ([github.com/Vinzent03/obsidian-git](https://github.com/Vinzent03/obsidian-git)) می‌توانید مستقیماً از داخل Obsidian کامیت و پوش کنید.

### نصب و راه‌اندازی

1. ابتدا Obsidian را دانلود و نصب کنید: [https://obsidian.md/download](https://obsidian.md/download) (اندروید: گوگل‌پلی یا [https://obsidian.md/mobile](https://obsidian.md/mobile)).
2. در اولین اقدام پس از باز کردن نرم افزار، گزینه‌ی **Open folder as vault** را انتخاب کنید و پوشه‌ی ریپوی کلون‌شده (`cs-daily-report`) را به‌عنوان vault باز کنید.
3. از **Settings → Community plugins** پلاگین‌ها را فعال کنید.
4. روی **Browse** بزنید، دنبال پلاگین **Git** (نویسنده: Vinzent03) بگردید، **Install** و سپس **Enable** کنید.
5. سپس Obsidian را ری‌استارت کنید. (اختیاری)

### استفاده روزانه

1. فایل گزارش استپ خود (`CSI - Report - ...`) را باز کنید و گزارش روز را در آن پر کنید.
2. بعد از تکمیل گزارش: `Ctrl+P` (یا Command Palette موبایل) → دستور **Commit-and-sync** را اجرا کنید؛ این دستور همه‌ی تغییرات را کامیت، پول و پوش می‌کند. می‌توانید از **Source Control View** هم برای انتخاب فایل‌ها استفاده کنید.
3. بعد از push، لینک کامیت را از **History View** یا از خود گیت‌هاب کپی کنید و طبق گام ۷ در تلگرام ارسال کنید.

### نکات مهم (به‌ویژه برای اندروید)

> **نکته:** روش پیش‌فرض ارسال گزارش از طریق **کامپیوتر** است. توضیحات مربوط به موبایل فقط برای شرایط خاصی اضافه شده که دسترسی به کامپیوتر وجود ندارد، تا گزارش‌ها هر روز بدون وقفه ارسال شوند.

- پشتیبانی موبایل این پلاگین هنوز **آزمایشی (Experimental)** است و ممکن است ناپایدار باشد، مخصوصاً روی دستگاه‌های کم‌حافظه. برای گزارش روزانه، بهتر است کامیت و پوش نهایی را از روی دسکتاپ انجام دهید.
- در موبایل، احراز هویت SSH پشتیبانی نمی‌شود و باید از HTTPS با توکن گیت‌هاب استفاده کنید. توکن را از مسیر زیر بسازید: GitHub → **Settings → Developer settings → Personal access tokens → Tokens (classic)**.
- در موبایل ابتدا یک Vault بسازید، سپس از طریق Command Palette دستور git clone را اجرا کنید.
- اگر در موبایل مشکل داشتید، پلاگین رایگان **GitSync** ([github.com/ViscousPot/GitSync](https://github.com/ViscousPot/GitSync)) جایگزین مناسبی برای اندروید و iOS است.
- مستندات کامل پلاگین: [https://publish.obsidian.md/git-doc](https://publish.obsidian.md/git-doc)

علاوه بر Obsidian، دو ابزار دیگر هم پیشنهاد می‌شوند که اگر خواستید می‌توانید درباره‌شان بیشتر بخوانید:

- **GitHub Desktop** ([https://desktop.github.com](https://desktop.github.com)) — گیت را با رابط گرافیکی مدیریت می‌کند و مفاهیم کامیت (commit) و پوش (push) را شهودی‌تر و ملموس‌تر می‌کند.
- **VS Code** ([https://code.visualstudio.com](https://code.visualstudio.com)) — یک ویرایشگر حرفه‌ای Markdown که ابزارهای گیت را هم در خودش دارد.

## چک‌لیست روزانه

1. گزارش روز را در فایل استپ خود (`CSI - Report - ...`) پر کنید: تسک‌ها، ساعت روز، و لینک‌های شبکه‌های اجتماعی.
2. کامیت بزنید و پوش کنید (`git add` → `git commit` → `git push` یا فرمان **Commit-and-sync** در Obsidian).
3. لینک کامیت را کپی کنید (تب Commits در گیت‌هاب یا History View در Obsidian).
4. در گروه **CS Internship - Coordination**، تاپیک **Reports**، پیام گزارش + لینک کامیت را ارسال کنید و کوردینیتور را منشن کنید.
5. این کار را هر روز تکرار کنید؛ یک کامیت برای هر روز.
